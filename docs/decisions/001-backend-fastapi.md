# Entscheidung: FastAPI als Backend

## Alternativen
- Django
- FastAPI
- NestJS

## Entscheidung
FastAPI

## Gründe
- Python
- gute Integration mit KI
- leichtgewichtig
- klare API-Struktur
- automatische OpenAPI-Dokumentation

## Nachteile
- weniger "all inclusive" als Django
- Authentifizierung muss stärker selbst aufgebaut werden
